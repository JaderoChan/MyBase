# Markdown 风格规范

## 根本

Markdown 的编写风格需要符合此仓库规范：[DavidAnson/markdownlint](https://github.com/DavidAnson/markdownlint)

## 样例

你需要根据以下样例的风格生成规范的 Markdown 文档。

```markdown
<!-- Markdown 文档必须包含一级标题 -->
# 这是一级标题
<!-- 各级标题与正文之间必须使用一行空行分隔 -->

这是正文部分段落一
<!-- 段落之间必须使用一行空行分隔 -->

段落二

<!-- 表格的单元格内容与列符号“|”必须使用空格分隔，对于表头和表体间的分割线部分也同样适用 -->
| TH1 | TH2 | TH3 |
<!-- 表头与表体间的分割线部分固定使用三个短横线 -->
| --- | --- | --- |
| ... | ... | ... |

## 这是二级标题

- 列表项
- 列表项
<!-- 对于子级内容或，必须使用一行空行使之与父级内容进行分隔 -->

    - 子列表项
    - 子列表项

- 列表项
```

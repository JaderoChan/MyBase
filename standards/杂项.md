# 杂项

1. **Git** 的 commit 信息不对首字母（缩写除外）进行大写。
2. 任何时候，相对路径都应该以 `./` 开头。（例如 **Markdown**、**CMake** 和脚本文件中的相对路径）
3. 编写 **C/C++** 代码时对于表示某一事物数量的变量应该以 `numVars` / `num_vars` 的形式命名。（例如 `num_channels`，`num_items`）

    > 如果使用 `varNum` 的形式命名容易与“编号”语义混淆。

    对于 **Java** / **C#** 则以 `varCount` 的形式命名。（例如 `channelCount`，`itemCount`）

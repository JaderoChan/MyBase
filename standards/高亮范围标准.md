# 高亮范围标准

- 小标题的高亮范围应该高亮真正需要被强调的部分（与小标题强相关内容）。冒号 `:` 通常仅具备“承上启下”的连接作用，不与小标题强相关，所以通常不被包含在内；`!` `?` 等句点通常与小标题强相关，所以通常被包含在内。

    **示例**：

    ---

    ```markdown
    **额外说明：**

    一些额外说明
    ```

    ❌ 错误

    ---

    ```markdown
    **额外说明**：

    一些额外说明
    ```

    ✅ 正确

    ---

    ```markdown
    **为什么**？

    因为……
    ```

    ❌ 错误

    ---

    ```markdown
    **为什么？**

    因为……
    ```

    ✅ 正确

    ---

- 引用/补充说明的高亮范围不包含引号等包围符号。

    **示例**：

    ---

    ```markdown
    上班偷懒也被叫做 **“磨洋工”**。
    ```

    ❌ 错误

    ---

    ```markdown
    上班偷懒也被叫做 “**磨洋工**”。
    ```

    ✅ 正确

    ---

    ```markdown
    需要进行某些操作 *(参见：https://....)*。
    ```

    ❌ 错误

    ---

    ```markdown
    需要进行某些操作 (*参见：https://....*)。
    ```

    ✅ 正确

    ---
